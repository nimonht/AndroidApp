CommandRegistry

class CommandRegistry

Central registry for all console commands.

Commands are registered at application startup (via the DI container) and looked up by name or alias during command resolution. The registry also supports role-filtered listing, prefix-based autocomplete for the console input field, and aggregation of command-declared value flags for the parser.

Thread safety: registration is expected to happen once at startup on the main thread. After that, resolve, allCommands, commandsForRole, autocompleteCommand, allValueFlags, and allShortValueFlags are read-only and safe to call from any thread.
