CommandFormatUtils

object CommandFormatUtils

Shared formatting utilities for console command output.

Consolidates common string formatting functions previously duplicated across individual command implementations: truncation, padding, JSON escaping, CSV escaping, timestamp formatting, duration formatting, and role/permission display names.
