CommandExecutor

class CommandExecutor(registry: CommandRegistry, contextProvider: () -> CommandContext)

Orchestrates the full lifecycle of console command execution: lexing, parsing, resolution, role/permission checks, destructive confirmation checks, and finally execution with pipe/chain support.

The executor is the single entry point used by the console ViewModel. It delegates to CommandLexer, CommandParser, and CommandRegistry internally.
