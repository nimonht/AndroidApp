ConsoleJsonBuilder

object ConsoleJsonBuilder

Lightweight JSON builder for console command output.

Generates pretty-printed JSON as a list of OutputLines styled with OutputStyle.CODE. All string values are escaped via CommandFormatUtils.escapeJson to prevent injection and ensure valid JSON output.

Usage:

val lines = ConsoleJsonBuilder.buildObject {
    field("name", "value")
    field("count", 42)
    field("active", true)
    array("items") {
        addObject {
            field("id", "abc")
        }
    }
}
