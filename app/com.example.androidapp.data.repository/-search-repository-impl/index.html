class SearchRepositoryImpl(context: Context) : SearchRepository

Implementation of SearchRepository that persists recent search queries using SharedPreferences and Gson for JSON serialization.

Recent searches are capped at MAX_RECENT_SEARCHES items, stored in most-recent-first order, and automatically deduplicated.
