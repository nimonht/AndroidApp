QuestionRepositoryImpl

class QuestionRepositoryImpl(questionDao: QuestionDao, choiceDao: ChoiceDao, remoteDataSource: QuestionRemoteDataSource, syncManager: SyncManager) : QuestionRepository

Room-backed implementation of QuestionRepository with Firestore sync.

Follows the local-first pattern: all writes are persisted to Room immediately, then SyncManager.enqueueSync is called to schedule background Firestore sync. Reads always return Room data; Firestore refresh happens externally.
