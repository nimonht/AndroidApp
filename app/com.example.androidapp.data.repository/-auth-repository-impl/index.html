AuthRepositoryImpl

class AuthRepositoryImpl(firebaseAuth: FirebaseAuth, userDao: UserDao, userRemoteDataSource: UserRemoteDataSource, firestore: FirebaseFirestore) : AuthRepository

Implementation of AuthRepository that wraps FirebaseAuth. On login/register, the user profile is cached in Room via UserDao.

The currentUser flow is backed by a MutableStateFlow that is updated by both FirebaseAuth.AuthStateListener (login/logout) and updateProfile (display name / photo URL changes), ensuring the UI always reflects the latest user data without requiring a re-login.
