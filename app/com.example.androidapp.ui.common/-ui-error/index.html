UiError

enum UiError : Enum<UiError>

Centralised error codes emitted by ViewModels.

ViewModels set a UiError value (instead of a raw Vietnamese string) so that the UI layer can map it to a localised message via toMessage. This keeps ViewModels free of Android resource dependencies while guaranteeing that every user-facing string lives in res/values/strings.xml.

The enum is grouped by feature area. Each entry documents which ViewModel(s) originally contained the corresponding hardcoded string.
