QuizFormHelper

object QuizFormHelper

Pure-Kotlin helper that centralises quiz-form logic shared by CreateQuizViewModel and EditQuizViewModel.

All functions are stateless and side-effect-free so that ViewModels remain the sole owners of mutable state and coroutine scopes.
