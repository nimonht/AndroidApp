CreateQuizEvent

sealed interface CreateQuizEvent

Create-specific events that are not shared with the edit flow.

Shared form events (title, description, questions, save/publish, etc.) live in QuizFormEvent. CreateQuizViewModel exposes two onEvent overloads so that both QuizFormEvent and CreateQuizEvent funnel through the same method name.
