ModelManager

class ModelManager(context: Context)

Manages the TFLite model lifecycle with a two-tier resolution strategy.

Resolution order (first success wins):

  1. Local cache -- previously copied model in Context.getFilesDir.

  2. Bundled asset -- copied from the APK asset to the local cache, or memory-mapped directly via openBundledAssetBuffer (zero-copy, fast).

The model (~6 MB) is bundled as an APK asset; no network download is needed.

Callers observe state to track loading progress and display appropriate UI (e.g., a loading indicator on the Search screen).
