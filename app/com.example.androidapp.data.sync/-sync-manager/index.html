downloadQuizzes
Link copied to clipboard
suspend fun downloadQuizzes(userId: String)

Download (pull) quizzes from Firebase and save to Room. This implements the Firebase -> Room sync direction. Uses SHA-256 checksums for efficient change detection: if both local and remote have a checksum and they match, the quiz content is identical and the download is skipped even when timestamps differ.
