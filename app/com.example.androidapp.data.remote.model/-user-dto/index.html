UserDto

data class UserDto(val id: String = "", val email: String = "", val displayName: String = "", val username: String = "", val photoUrl: String? = null, val role: String = "user", val permissions: List<String> = emptyList(), val createdAt: Timestamp? = null, val updatedAt: Timestamp? = null, val deletedAt: Timestamp? = null)

Firestore DTO for a user profile.

Includes createdAt and updatedAt timestamps required by the Firestore users schema. deletedAt supports soft-delete. role specifies user role ("guest", "user", "admin", or "superuser") - defaults to "user". permissions holds the list of admin permission strings granted to this user.
