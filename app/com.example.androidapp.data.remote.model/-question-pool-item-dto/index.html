Firestore DTO for a question pool item.

This structure aligns with the Firestore questionPool schema which stores question data in a flattened format with top-level fields.

Boolean properties prefixed with is use explicit @PropertyName annotations to prevent Java Bean naming conventions from stripping the prefix during Firestore serialization (e.g. isActive being stored as active).
