AdminRemoteDataSource

class AdminRemoteDataSource(firestore: FirebaseFirestore, functions: FirebaseFunctions, firebaseAuth: FirebaseAuth)

Remote data source for admin-level Firebase operations.

Provides elevated access to Firestore collections for administrative tasks. All methods assume the caller has been authorized as an admin.
